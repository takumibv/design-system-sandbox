# 社内ブログ投稿計画 ブリーフ

## 要望

> メンバーの社内ブログ投稿の計画を立てて、投稿予定を把握できるようにしたい。
> いまは Slack のスレッドとスプレッドシートでばらばらに管理していて、誰がいつ何を書くのかが分からなくなる。予定日を過ぎても気づかれずに止まってしまう記事もあるし、気づくと何週間も投稿が空いていることがある。

（依頼者：社内ブログの取りまとめ役）

## 達成したい目標

| # | 目標 |
| --- | --- |
| O1 | 社内ブログを、週 1 本以上のペースで途切れずに公開し続ける |
| O2 | 書く人や時期の偏りを減らす |
| O3 | 書く人が、自分の担当と予定日を忘れない |
| O4 | 取りまとめ役（編集担当）が、計画の抜けや遅れに早く気づける |

## 機能要件

### 投稿予定

- 投稿予定を登録・編集・削除できる。項目：
  - タイトル（仮タイトル可）
  - カテゴリ（技術／デザイン／チーム・文化／イベント報告）
  - 書く人（1 人以上。共著あり）
  - 公開予定日（未定でもよい）
  - 状態（アイデア／執筆中／レビュー中／公開済み／取りやめ）
  - 公開後の記事 URL、メモ
- 状態を変えられる。公開済みにしたら公開日と記事 URL を記録できる。
- 期間を指定して、投稿予定と公開済みの投稿を確認できる。
- 書く人ごとの予定と実績が分かる。
- 公開予定日が近い投稿、予定日を過ぎても公開されていない投稿が分かる。
- 投稿予定が入っていない週が分かる。
- 自分が書く投稿が分かる。

### メンバーと権限

- メンバーには役割がある：一般メンバー／編集担当。
- Slack アカウントでログインする（デモでは通知を出すだけでよい）。ログインしていなくても閲覧はできる。
- ログイン中の人は、投稿予定を登録し、自分が書く人に入っている投稿を編集できる。
- 編集担当は、すべての投稿予定を編集・削除できる。

### 共通

- 次のことが起きたとき、何が起きたかと次にできることが分かる：読み込み中、読み込みの失敗、データが無い、保存・削除の成功と失敗、権限の無い操作、存在しないページ。
- Gaji-Labo のサービスであることが分かる（`gaji-labo-logo.svg`。押すと https://www.gaji.jp/ が別タブで開く）。
- 文言は日本語。

## 固定データ

`fixtures.ts`：メンバー 10 人、投稿 15 件。今日は 2026-11-09（月）。ログイン中の自分は id=1（一般メンバー）、編集担当は id=2。データの保存は実装しなくてよい（画面内の状態だけでよい）。

## 撮影・検査

`scripts/capture.mjs`：`states.json`（`[{ "id": "...", "path": "/..." }]`）に並べた状態を 1440px／390px で撮影し、axe（WCAG 2.1 AA）と横はみ出しを検査する。
