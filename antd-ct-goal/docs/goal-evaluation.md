## 目標ごとの詳細

### G1 ◎

- 主役カード「今週のあなたの相手」に相手のアバター（64px、390px では 48px）と名前（h2）を出し、カード右上に「10月5日（月） 14:00〜」を出す（S01）。
- 自分がお休みの週は「今週はお休みです」と理由（奇数のため）、次の相手と日付を出す（S03：次は 10月19日 小林 結衣さん）。
- 祝日の週は「今週は CT がありません」＋祝日名の Tag ＋次の相手（S04）。
- 参加者 2 人未満は「今週の相手はいません」と理由（S05）。
- 未ログインでは同じカードが「ログインすると、今週の相手がここに表示され、そのままハドルを始められます」と Slack ログインの primary ボタンになる（S02）。

### G2 ◎

- 主役カードの「高橋 健太さんとハドルを始める」が画面で唯一の primary ボタン。ハドルの場所（#u-kenta、2 人で共通）をボタンの上に出す（S01）。
- 相手の uチャンネルが未設定なら、ボタンを出さず warning の Alert で「ここからはハドルを始められません。Slack で直接声をかけてください」と代わりの手段を示す（S09）。
- 全ペアの一覧にも各行に「ハドル」（text ボタン）がある。

### G3 ○

- 右列（390px では 3 枚目）の「これからの予定」に、次のお休み（S03 では「今週（10月5日（月））」、S01 では「11月2日の週まではありません」）、「先の週は予定」の注記、週ごとの「予定」Tag と「あなた：〇〇さん」を出す。
- 祝日の週は「CT なし・スポーツの日」の Tag（S01）。

### G4 ○

- メンバー画面に参加・不参加・初回設定未完了の人数（S11：9／2／1）と、社員番号順の一覧。参加と不参加はアイコンと文字の Tag で区別する。
- 削除は確認の Modal で「誰を」「元に戻せない」「参加中なら組み直し」を示し、danger の「削除する」で実行（S13）。成功は message、失敗はモーダル内の Alert と「もう一度削除する」（S14）。
- 0 人のときは Empty と「Slack でログイン」（S12）。

### G5 ○

- 「自分の設定」の Radio.Group で「参加する／参加しない（休職・繁忙期など）」を選ぶ。変えた時点で保存前に warning の Alert（「保存すると、組み合わせから外れます」「今週以降の組み合わせが全員分組み直しになり、他の人の相手も変わります」）。
- 保存の成功は message（S10）、失敗は消えない Alert（S17）。

### G6 ○

- 「はじめての設定」：目的の一文、各項目の「何に使うか」、名前は Slack の表示名を入れておく（S15）。
- 未入力のまま送信すると、項目ごとに「社員番号を入力してください」「uチャンネルを選んでください」（S16）。完了すると組み合わせの画面へ戻り、message で完了を伝える。
