- 型定義（`.d.ts`）は「その props があるか・非推奨でないか」（例：Alert の `message` は非推奨で `title` を使う、Modal の `focusTriggerAfterClose` は `focusable` へ、Space の `direction` は `orientation` へ）を確かめるためにだけ使った。どの部品を選ぶかの判断材料にはしていない。
- `node_modules/antd/README.md` は通読したが、内容は特徴・インストール・最小の使用例・リンクで、設計の判断に効く記述は無かった。
- 「事前知識（DS）」の判断はどれも、ハーネスあり版で確かめれば覆る可能性がある。特に確信度「中」の 4 件（Ribbon の使いどころ、List と Table の選び分け、Switch と Radio の使い分け、Skeleton と Spin の使い分け）。
