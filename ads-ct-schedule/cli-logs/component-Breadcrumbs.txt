Props (4)
  children       string | number | boolean | ReactElement<any, string | JSXElementConstructor<any>> | Iterable<React…
  The items to be included inside the Breadcrumbs wrapper.
  ellipsisLabel  string | undefined
  Text to be used as an accessible label for the ellipsis button that reveals collapsed breadcrumb items in a popup.
  label          string | undefined
  Text to be used as label of navigation region that wraps the breadcrumbs.
  size           "small" | "medium" | undefined
  The size variant of the breadcrumbs. Use `'small'` for a compact presentation with smaller text (`font.body.small`) and smaller icons.
