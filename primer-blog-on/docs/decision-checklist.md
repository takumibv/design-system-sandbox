## I20 自分で決めた仮定の一覧

| 仮定 | 内容 |
| --- | --- |
| 週の区切り | 月曜始まり。週の帰属は「公開済みなら公開日、それ以外は予定日」 |
| 抜けの定義 | 今週以降で、取りやめ以外の投稿が 0 件の週。過去の空き週は「公開なし」と表示するが「要対応」には数えない |
| 遅れの定義 | 予定日 < 今日 かつ 公開済み・取りやめ以外 |
| 近いの定義 | 今日から 7 日以内 |
| 既定の期間 | 2 週前の月曜から 8 週。選べる週数は 4／8／12 |
| 共著の数え方 | 書く人それぞれに 1 本 |
| 一般メンバーの削除 | 不可（ブリーフは「編集」のみ明記） |
| 取りやめの扱い | 状態の変更なので確認なし。削除は確認あり |
| ログインのデモ | 「Slack でログイン」を押すと id=1（佐藤 美咲）としてログインし、Banner で「デモのため Slack には接続していない」と通知 |
| デモ用の役割切り替え | URL の `?as=guest|member|editor`（既定は member＝id=1） |
| 擬似状態 | `?state=loading|error|empty`、`?error=save|delete|validation`、`?fail=save|delete`、`?dialog=publish|delete`、`?result=…` |
| 公開の記録 | 公開日の既定は今日、記事 URL は必須（ダイアログ）。フォームからの公開済みは URL 任意 |
| 未保存の破棄確認 | 入力を変えてから「キャンセル」で ConfirmationDialog。ブラウザの戻る・再読み込みでは警告しない |
| 端末 | スマホ（390px）でも全機能を使える |
