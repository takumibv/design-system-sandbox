## I20 の詳細：自分で置いた仮定

| 仮定 | 内容 | 影響する画面 |
| --- | --- | --- |
| 利用頻度・時刻・端末 | 取りまとめ役は週 1 回、書く人は月に数回、主にパソコン | 最初の画面の主役、モバイルの扱い |
| 週の区切り | 月曜始まり〜日曜 | V1 |
| 週の本数の数え方 | 取りやめは数えない。アイデアでも日付があれば数える。公開済みは公開日の週、それ以外は公開予定日の週 | V1、確認が必要なこと |
| 「遅れ」の定義 | 公開済み・取りやめ以外で、公開予定日 < 今日 | V1・V2・V4 |
| 「近い」の定義 | 公開予定日まで 14 日未満（今日を含む） | V1 の自分向け案内、V2 |
| 既定の期間 | 今週の 2 週前から 10 週。前後の送りも 10 週 | V1 |
| 空き週の対象 | 表示中の期間のうち今週以降の週。過去の週で公開が無かった場合は週の中だけで警告 | V1 |
| 書く人の集計範囲 | 全期間（期間で絞らない）。「これからの予定」は公開済み・取りやめ以外（日付未定を含む） | V3 |
| 追加の初期値 | 書く人＝ログイン中の自分、カテゴリ＝技術、ステータス＝アイデア | 追加ダイアログ |
| 公開済みにしたときの公開日の初期値 | 今日 | 公開済みにするダイアログ |
| 記事 URL の検査 | 任意。入れるなら http(s):// から | ダイアログ |
| Slack 通知の内容 | 公開予定日の前日に書く人へ（デモの文言のみ） | ログイン通知 |
| 取りやめの扱い | 削除とは別。確認なしで変更でき、戻せる | V4、編集ダイアログ |
| 権限の無い操作を URL で開いたとき | ダイアログを開かず、エラー通知 | 全画面 |
| 閲覧者の切り替え（デモ） | URL の `?as=guest/member/editor`（既定は member＝id=1） | 全画面 |
