# 判断チェックリスト（ハーネスなし版）

根拠の種類は次のどれか。1 つの判断に複数あるときは主なものを先に書いています。

- **ブリーフ**：`brief/README.md` の文（引用）
- **事前知識（DS）**：Primer について自分がもともと知っていたこと（確信度 高／中／低）
- **事前知識（一般）**：デザインシステムに依らない UI・アクセシビリティの知識
- **型定義・README**：`node_modules` の `.d.ts`・README（ファイル名）
- **検査**：axe・横はみ出しの結果
- **その他の自分の判断**

なお「撮影を見て直した」ものは、共通の検査（axe・横はみ出し）では見つからず、自分で画像を見て気づいたものなので「その他の自分の判断」に入れています。

### 気づいたこと

- Primer の**事前知識（DS）に頼った判断は、どれも確信度が「中」以下**でした（Blankslate が空の状態の部品であることだけ「高」）。特に「primary は 1 画面 1 つ」「ToggleSwitch と Checkbox の使い分け」「Flash より Banner」「Header は GitHub の黒い帯」は、記憶にあっても出典を確かめられていません。ハーネスあり版で、これらが同じ結論になるか・根拠が示されるかが比較の要点だと考えます。
- **型定義のコメントが実質的なガイドラインとして効いた**のは 2 か所です：`ConfirmationDialog` の初期フォーカス（危険な操作ではキャンセル）と、`Spinner` の `srText={null}`。
- **検査（axe・横はみ出し）は判断に一度も効きませんでした**。一方で、390px の表の見切れや、祝日の週の「14:00 開始」との矛盾など、撮影を目で見て直したものが 6 件ありました（`docs/design-decisions.md` 実装後の追記）。
